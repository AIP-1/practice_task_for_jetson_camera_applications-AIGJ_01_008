# 기능 시험 기록 (T0~T4)

AIGJ_01_008 박민수 · 11/3 · 공통 조건: Jetson Orin Nano Super 8GB, JetPack 7.2.1, MAXN\_SUPER, 호스트 venv, A1·A3 서비스 가동 중. 카메라는 C920(USB)과 VIGI C540-W(RTSP, 서브 848x480). 실습 키트가 없어 `code/`의 직접 만든 도구로 쟀다. 자세한 과정은 [../docs/DETAILS.md](../docs/DETAILS.md).

## T0. 카메라 연동 (과제 1)

**T0-1 수신**
- 조건: C920 1280x720, VIGI 서브 848x480, `cam1.py`
- 결과: C920 30.0 fps·첫 프레임 638 ms·CPU 35.7%, VIGI 27.1 fps·1216 ms·6.3%
- 판정: 합격

**T0-2 원격 뷰어**
- 조건: MJPEG 뷰어를 Mac 브라우저로 원격 접속
- 결과: C920 1280x720은 지연이 5초에서 18초로 늘고 깨짐, 640x480은 1초 이하. VIGI 640x480 수신 25.2 fps
- 판정: 합격 (뷰어는 640x480으로 운영)

**T0-3 초점·각도**
- 조건: 줄자, 각도는 눈대중, C920 초점은 `v4l2-ctl`
- 결과: C920 높이 1.2 m·아래 15°·1.08 m부터 보임·자동 초점 켜짐. VIGI 높이 1.08 m·수평·0.86 m부터 보임
- 판정: 합격 (과제 5는 자동 초점을 끄고 촬영)

**T0-4 지연 누적**
- 조건: 프레임마다 0.2초 처리 지연, 120초, (a) `read()` 반복 / (b) 최신 1장 리더
- 결과: VIGI (a) 96.2초 증가, (b) 증가 없음. C920 (a) 약 0.85초에서 멈춤, (b) 약 8 ms
- 판정: 합격 (차이와 원인 계산 일치: 0.8초/초 × 120초 = 96초)

**T0-5 재연결**
- 조건: VIGI 랜선을 뽑았다 다시 꽂음 (과제 6 분리 시험과 같은 시험)
- 결과: A1·A3 모두 재시작 없이 재연결 1회. A1은 끊김을 5.7초 안에 표시하고 다시 연결된 읽기 2초 뒤 `정상`. A3 복구 뒤 22.1 fps
- 판정: 부분 합격 (자동 복구는 확인, 꽂은 시각을 적지 않아 "30초 안"은 수치로 못 보임)

**T0-6 glass-to-glass**
- 조건: 640x480 원격 뷰어. C920은 눈대중, VIGI는 영상 속 카메라 시계(NTP)와 브라우저 시계 비교
- 결과: C920 1초 이하. VIGI 새로고침 직후 4.7초, 61초 뒤 6.6초 (늘어난 부분은 뷰어 전송 밀림)
- 판정: 합격

## T1. 물체 인식 (과제 2)

**T1-1 벤치마크**
- 조건: 입력 640, 임의 영상 200회, mAP는 coco128, 전력은 tegrastats 보드 전체
- 결과: PyTorch yolo11n 29.03 ms(p95 30.47, mAP 0.508), yolo11s 29.97 ms(0.576), TensorRT FP16 yolo11n 전체 11.48 ms(p95 14.87, 87.1 fps, mAP 0.503), 추론만 5.1 ms(coco128 검증)
- INT8: 서비스를 잠시 끄고 coco128 보정으로 변환, 8분 제한 안에 끝나지 않아 멈춤 (최소 남은 메모리 1390 MB)
- 판정: FP16 추론 기준 10 ms 충족

**T1-2 선 통과**
- 조건: VIGI 서브, yolo11n conf 0.4, ByteTrack, 2~3 m, MQTT `aiot/vision/test/event` 발행 (18:48)
- 결과: 10회 중 10회 맞음 (IN 5, OUT 5, 중복 0). 구독 기록에 MQTT 메시지 10개. 앞선 15:09 기본 추적기 9회도 9/9
- 판정: 합격 (오차 0 ≤ 1)

**T1-3 조명×거리**
- 조건: VIGI 서브, 칸마다 30초, 검출률은 신뢰도 0.4 이상 프레임 비율
- 결과: 0.93 m·2 m × 밝음·어두움 4칸 모두 검출률 95.1~100%, 신뢰도 0.88~0.95
- 판정: 부분 (방이 2 m까지라 5·8 m 없음, "어두움"은 낮에 앞 조명만 꺼 화면 밝기가 거의 같음)

**T1-4 물품 인식**
- 조건: VIGI 서브 약 1 m, 우산·컵·꽂이·상자·줄자, 라벨 목록 9개
- 결과: yolo 1/5, relabel 5/5, yoloe 2/5 (yoloe는 틀린 이름 0, 3개 못 잡음)
- 판정: 불합격 (개방 어휘 기준 4/5, COCO 밖 물품은 3종)

## T2. 재실 인원 (과제 3)

- 조건: A1, VIGI, yolo11n 640, 30초 median, 1분마다 기록
- 결과: 밤 빈 방 657칸 오판 0%. 낮 30분 30칸 MAE 0.00. 1명 칸 5개 MAE 0.40(순간 5/5, 중간값 3/5). 2명까지 10분 10칸 MAE 0.00
- 원인: 중간값이 틀린 2칸은 사람이 들어온 지 10~15초 된 시점(창 지연)
- 판정: 합격 (세 기준 모두 충족, 2명 칸 1개·출입 계수 비교 없음)

## T3. 행동 패턴 (과제 4)

- 조건: A3, VIGI 서브, yolo11n-pose, 0.6초 다수결, 2~3 m
- 결과: 만세 10/10(중복 0). 한팔 정지 약 12회 중 11회 정답, 손흔들기 오판 1(만세로 넘어가는 순간 1회 제외). 행동 12회 11/12(머무름 재측정 반영). 혼동 사례 5건. 악수는 원래 기준 0회, 완화 뒤 약 4회 중 3회, 가까이 서기만 했을 때 오검출 0번
- 원인: 팔을 빠르게 올리고 내릴 때 손목이 좌우로 지나가 흔들기 규칙에 걸림. 악수는 맞잡은 손목의 신뢰도 하락
- raw 비교 (18:57, 만세 10회 동시 측정): raw 10/10이지만 `한팔들기` 깜빡임 12번, 안정화 10/10에 깜빡임 0(중복 1), 판정은 평균 약 0.3초 늦음
- 판정: 합격

## T4. 거리 측정 (과제 5)

- 조건: 같은 모델 웹캠 2대가 없어 C920 1대를 8 cm 옮겨 두 번 촬영(대체), 640x480, 자동 초점 끔, 두 기준점으로 회전·기울기 보정
- 결과: 의자 1.4 m → 1.35 m(−3.6%). 꽂이 1.9 m → 2.12 m(윗면, +12% 이하). 가상 시차 시험 3점 0.02 px 안
- 판정: 불합격 (정식 스테레오 보정·3~4 m·측정 불가 조건 없음, 1.4 m 한 점만 기준 안)

## 추가. 장애 시험 (과제 6)

- 조건: 팀원 동의 후 `sudo reboot`, systemd 자동 시작, 11/3 16:29
- 결과: 부팅 16:29:41, A1 첫 기록 16:30:10(`정상`), A3 첫 1분 기록 16:31:07(20.9 fps). 명령 후 A1 약 1분, A3 2분 안
- 판정: 합격 (3분 기준)
