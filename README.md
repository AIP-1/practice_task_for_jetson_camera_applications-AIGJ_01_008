| 과제 | 상태 |
| --- | --- |
| 1. 카메라 연동과 기준선 | 진행 중 (측정 대부분 완료, 재연결 남음) |
| 2. 물체 인식 | 진행 중 (PyTorch·TensorRT FP16 벤치마크 완료, 현장 시험 남음) |
| 3. 재실 인원 카운터 | 진행 중 (빈 방 오판율 0%, 낮 30분 시험 MAE 0.00명, 사람이 많은 시간 재평가 남음) |
| 4. 행동 패턴 인식 | 진행 중 (행동 12회 재측정 반영 11/12, 만세 10/10, 한팔 WAVE 오판 2/12, 악수 남음) |
| 5. 거리 측정 | 진행 중 (웹캠 1대 이동 대체 측정, 의자 −3.6%) |
