# Jetson 카메라 응용 실습

AIGJ_01_008 박민수. **이 과제는 진행 중이다.** 결과와 확인 문제 답안 초안은 [REPORT.md](REPORT.md)에 있다.

| 과제 | 상태 |
| --- | --- |
| 1. 카메라 연동과 기준선 | 진행 중 (측정 전) |
| 2. 물체 인식 | 진행 중 (측정 전) |
| 3. 재실 인원 카운터 | 진행 중 (서비스 가동, 정확도 평가 전) |
| 4. 행동 패턴 인식 | 진행 중 (서비스 가동, 시험 전) |
| 5. 거리 측정 | 진행 중 (측정 전) |
| 6. 응용 서비스 | 진행 중 (12시간 가동 완료, 장애 시험 전) |

| 파일 | 내용 |
| --- | --- |
| `code/occupancy_service.py` | 재실 인원 서비스 (A1) |
| `code/cam1.py` | 카메라 연동 측정 도구 (과제 1) |
| `code/pose_app.py` | 행동 패턴 서비스 (A3, MQTT 발행, 가동 기록) |
| `code/pose_model.py` | 관절 특징과 GRU 모델 |
| `code/*.service` | systemd 서비스 파일 |

카메라 비밀번호는 Jetson의 설정 파일에서 읽으며 저장소에 넣지 않는다. 영상과 사진도 넣지 않았다.
